📊 Dashboard de Distribuição por Torres e Unidades

Os saldos para distribuição são alimentados automaticamente pelos recebimentos lançados na aba Recebimento de Revestimentos. A distribuição por unidade reduz o saldo disponível do respectivo lote.

Selecione uma aba abaixo: Visão Geral ou uma das quatro torres para visualizar e lançar a distribuição.

Unidade

Confirmar ação

Aplicar lote às unidades selecionadas

A seleção é vinculada obrigatoriamente a um recebimento com saldo. A quantidade de cada unidade é calculada pelo material previsto e descontada do saldo do lote.

Selecionar unidades — qual material?

Ao escolher um material, apenas as unidades que usam esse piso como principal ficam clicáveis no prédio — as demais aparecem esmaecidas, evitando aplicar o lote errado. Escolha "Sem filtro" para selecionar livremente.

Distribuir lote automaticamente

O saldo exibido vem diretamente dos recebimentos lançados na aba Recebimento de Revestimentos. Informe a área a distribuir (m²), limitada ao saldo disponível do lote selecionado. O sistema preenche as unidades cujo material previsto em projeto corresponde ao selecionado, em ordem do térreo para o topo, descontando a área necessária de cada unidade — só preenche a unidade se sobrar área suficiente para ela inteira. Unidades já preenchidas não são alteradas. Se a área informada não for suficiente para todas as unidades, a sobra em m² fica registrada no visualizador de sobras da torre.
